# レックス英語マスター v88.0

v88は、v87.2をベースに学習体験を改善した版です。

- レックスの成長スピードをゆっくりに調整
- テストの日本語問題で、英語が疑問文の場合は日本語側にも「？」を表示
- テストで正解したら、正解英文を英語音声で読み上げ
- 正解時・会話時のレックスの褒め言葉パターンを追加
- レックスとのおしゃべりに自由入力欄を追加
- 教科書で習った文を使って、レックスが質問しながら会話を続ける簡易会話モードを追加
- Safariキャッシュ対策はv87.2から継続

GitHubには、このZIPを解凍した中身をリポジトリ直下へ上書きアップロードしてください。
