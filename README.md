# レックス英語マスター v87.1

v86/v87をベースに、Get Ahead Unit1〜4の教材データ品質を改善した版です。

## 主な変更

- `PE` / `P.E.` を正式表記の `physical education` に統一
- 「今日は体育を持っていますか。」など不自然な日本語を修正
- ボタン文言を中学生向けに改善
  - 正誤判定 → 答え合わせ
  - 出題 → 次の問題
  - 英文を聞く → 英語を聞く 🔊
  - 答えを見る → お手本を見る
  - できた → ○ わかった！
  - 間違いに追加 → 苦手に追加
- v85の安定音声・日本語読み補正は維持

## アップロード方法

ZIPを解凍し、中身のファイルをすべてGitHubリポジトリ直下へ上書きアップロードしてください。
フォルダごとではなく、`index.html` がリポジトリ直下にある状態にします。
